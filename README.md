## 核心系统架构与功能

### 1. 业务逻辑完全 1:1 还原与优化
- **📦 实时库存台账**：
  - 公式：`实时库存 = 上期库存 + 采购入库数量 - 销售出库数量`
  - 金额：`库存金额 = 实时库存 × 采购进价`
  - 自动预警：当库存低于安全库存（默认 30 件）时，全系统高亮预警并生成采购补货建议。
- **📈 客户应收台账**：
  - 公式：`应收金额 = 上期结转应收 + 销售金额 - 已收金额`
  - 自动核算欠款在全司总应收中的占比与催款优先级排名。
- **📉 供应商应付台账**：
  - 公式：`应付金额 = 采购金额 - 已付金额`
  - 自动核算应付账款占比与账期管理排名。
- **毛利与价格波动核算**：
  - 自动比对销售成交价与标准标价，统计实际销售毛利与毛利率。

### 2. AI 异构表格上传与实时更新（核心亮点）
- **多模态表头与别名自适应**：哪怕新上传的表格列名叫「货品/进货量/供货商」或「出货单号/业务员/收货客户」，系统都能精准识别。
- **SKU 与客商名称模糊对齐**：表格中写「轻便系列运动衣 黑」或「四季休闲服-红色」，AI 自动与数据库标准 SKU 对齐，防止重复乱建商品。
- **空公式自动剥离**：彻底解决原 Excel 末尾近千行 `,,,0,,0,0,,,0,,` 导致表格卡死或误算的问题。
- **入账前后联动推演（Before → After）**：上传表格后立即生成沙箱推演卡片，清晰展示本次更新将影响哪些商品的库存、哪些客户与供应商的账款，点击确认后正式写入数据库；亦可勾选“自动直通入账”。

### 3. 数据安全与时光机回滚
- **SQLite 本地落盘**：断电、清理浏览器缓存永不丢失数据。
- **批次级事务回滚**：万一传错表格，可在「导入批次与时光机」页面针对该批次点击「一键撤销」，库存与往来账款瞬间回退到上传前状态。

### 4. AI 财务助手与自然语言记账
- 支持自然语言一键记账：例如直接输入 *“向公司2补货轻便系列运动衣黑色50件”* 或 *“收到客户3微信转来货款15000元”*，系统自动生成推演卡片入账。
- 支持一键生成对账催款函：点击客户应收表右侧的「生成催款对账单」，AI 自动汇总该客户历史欠款、本期拿货及回款情况，并生成标准催款话术。
